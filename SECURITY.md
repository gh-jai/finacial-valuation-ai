# Security Policy

## Supported versions

Before v1.0, only the latest commit on the default branch is supported.

## Reporting

Report vulnerabilities privately through GitHub Security Advisories when enabled. Do not open a public issue containing secrets, private financial data, exploit details, or copyrighted source material.

## Data handling

Never commit API keys, credentials, client records, personally identifiable information, material non-public information, proprietary models, or private source files. Use synthetic benchmark data. Treat extracted text and model-generated content as untrusted input; validate paths and structured data before processing them.

FVI artifacts must not be treated as autonomous investment instructions. Human review is required before outputs influence real financial decisions.
