# Going-concern Value and Discrete Failure Risk

Use `survival × going-concern value + failure × failure value`. Probabilities reconcile to one. Failure value records basis, recovery rationale, evidence, and beneficiary. Key-person risk requires a separately valued operating scenario, never a post-value percentage discount.

## Failure modes

Basis mismatch, duplicated survival premium, failure loss embedded in FCFF, or arbitrary key-person haircut.

Implements `CLM-YNG-021` through `CLM-YNG-026`, printed pages 302–311.
