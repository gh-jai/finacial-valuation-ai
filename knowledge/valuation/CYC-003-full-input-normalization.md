# Full-input Cycle Normalization

Use a representative full-cycle or sector window. Absolute averages require comparable scale; relative averages apply a normalized ratio to a reconciled current scale; sector averages preserve company-specific adjustments; commodity normalization begins with a supported external driver.

The result is one internally consistent operating and financing state. Historical normalization is prohibited after an unstable regime or structural break unless a new regime independently supports it.
