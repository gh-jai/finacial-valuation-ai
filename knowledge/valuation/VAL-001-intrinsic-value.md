# Intrinsic Value as a Decision Estimate

## Summary

Intrinsic value is an estimate, as of a specified date, of the economic value supported by expected future benefits and the risks surrounding them. It is a decision aid rather than an observable fact. A useful estimate exposes its assumptions, range, evidence, and sensitivity to uncertainty.

## Core principles

1. Define the valued interest, date, currency, unit, and value basis before calculating.
2. Connect forecasts to an explicit narrative about operations, reinvestment, competition, and risk.
3. Match cash-flow definition and discount rate consistently.
4. Use scenarios or sensitivities for consequential uncertainty.
5. Reconcile the result to alternative evidence without forcing agreement.

## Application

A DCF is one implementation: forecast eligible cash flows, estimate a continuing value where appropriate, discount each amount to the valuation date, and bridge from enterprise value to the requested equity or per-share basis.

## Limitations

The estimate can be dominated by distant assumptions, poor base data, inconsistent units, or false precision. Market price may differ for rational reasons including information, liquidity, control, and timing. Human review is required before the output supports a real decision.
