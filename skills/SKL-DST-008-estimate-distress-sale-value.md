# Estimate Distress-sale Value

Apply one disclosed method: going-concern haircut, existing-asset earnings power, or adjusted book assets. Expose excluded growth assets, impairment, urgency, costs, and beneficiary. Reject book value without economic and sale-condition adjustments.
