# Template authoring contract

These files are copy-and-fill starting points for contributors and AI agents. Do not edit a template into a production artifact in place.

1. Copy the relevant template to its governed directory.
2. Replace every angle-bracket or date placeholder; no placeholder may remain in a reviewed artifact.
3. Use a stable ID, semantic version, ISO date, registered source IDs, and existing dependency IDs.
4. Keep `source_refs` empty when an artifact is wholly original. Never invent a citation to make the list non-empty.
5. Distinguish source statements, derived rules, and model inferences under `CITATION_POLICY.md`.
6. Define inputs, outputs, stop conditions, limitations, and human-review gates explicitly.
7. Validate the artifact before promotion. Templates themselves are intentionally not schema-valid until placeholders are replaced.

Markdown body instructions are minimum sections. Add detail when it improves reproducibility, but do not paste copyrighted source text.
